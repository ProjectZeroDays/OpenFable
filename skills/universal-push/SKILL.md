# universal-push

Universal `/push` command macro for swarm orchestration.

- `/swarm` activation
- Complete all tasks in TASKS_CHECKLIST.md
- Complete all parked / skipped / previous incomplete tasks
- Test, debug, add screenshots (web, .exe, .apk, .dmg, .ipa, .deb, .snap)
- Update documentation
- Create updated release with assets

Macro definition: `packages/opencode/src/skill/macro/push.yaml`
